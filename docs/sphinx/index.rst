Avian Biosurveillance
=====================

A passive-acoustic early-warning platform for unusual changes and mortality in
Dutch bird populations, built on public data. It turns continuous,
citizen-science bird-audio recordings into a weekly, spatially-resolved anomaly
signal for expert review.
